# LIXIANG-REMOTE-DISPLAY

Android app skeleton for LIXIANG Multi-Screen YouTube (premium UI prototype).

This repository contains an initial MVP Android project skeleton with a simple WebView-based YouTube player and placeholders for Firebase integration and multi-display sync.

How to build

1. Install Android Studio and Android SDK (API 33).
2. Open the project in Android Studio (root folder).
3. If you plan to use Firebase, place your google-services.json into `app/` and follow the Firebase setup.
4. Build and run the `app` module. A debug APK will be generated via Build -> Build Bundle(s)/APK(s) -> Build APK(s).
